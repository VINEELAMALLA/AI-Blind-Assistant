# 👁️ AI Virtual Assistant for Visually Impaired

## 📌 Overview

This project is an AI-powered virtual assistant designed to help visually impaired individuals understand their surroundings. It uses computer vision and deep learning to detect objects in real time and provides voice-based guidance.

## 🚀 Features

* Real-time object detection using YOLOv8
* Voice feedback for scene understanding
* Live camera input processing
* Assistive navigation support
* Works in dynamic environments

## 🛠️ Tech Stack

* Python
* YOLOv8 (Ultralytics)
* OpenCV
* Text-to-Speech (pyttsx3 / gTTS)

## ⚙️ How It Works

1. Captures live video from webcam
2. Detects objects using YOLOv8 model
3. Generates contextual descriptions
4. Converts output to speech for user guidance

## 📊 Results

* Real-time detection performance
* Robust in varied lighting and environments
